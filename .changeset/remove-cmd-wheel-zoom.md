Removed Cmd+scroll-wheel zoom. Too easy to trigger by accident while scrolling a column with the Cmd key tap-held (focus pivots, modifier-key holdovers), which yanked the whole UI mid-scroll. ⌘+/⌘-/⌘0 keyboard shortcuts + the Settings → Appearance sliders cover the same zoom surface without the footgun. Updated the in-app hint to drop the "⌘+scroll wheel" callout.
